# Лабораторная работа №3

**Тема:** Решение задач по основам языка JavaScript.

**Цель:** Изучение базового синтаксиса JavaScript, работы с функциями, замыканиями, рекурсией, побитовыми операторами и объектами.

### Что сделано

В файле `src/core.js` реализованы функции для решения 10 типовых задач:

1. `isInteger(n)` — проверка числа на целочисленность с помощью побитовых операторов.
2. `even()` — генерация массива четных чисел.
3. `sumTo(n)` — вычисление суммы чисел через цикл.
4. `recSumTo(n)` — вычисление суммы чисел через рекурсию.
5. `factorial(n)` — вычисление факториала числа.
6. `isBinary(n)` — проверка, является ли число степенью двойки.
7. `fibonacci(n)` — нахождение N-го числа Фибоначчи.
8. `getOperationFn(initialValue, operatorFn)` — создание функции-замыкания для выполнения математических операций с сохранением состояния.
9. `sequence(start, step)` — создание генератора арифметической последовательности.
10. `deepEqual(firstObject, secondObject)` — глубокое рекурсивное сравнение объектов и массивов.
